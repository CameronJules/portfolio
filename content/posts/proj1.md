# Sample Project

## Overview

This is a sample post to demonstrate how the portfolio system works. Drop your own `.md` files into `content/posts/` and images into `public/posts/<slug>/`.

The first image in your markdown becomes the grid thumbnail.

## How it works

Markdown is pre-processed at build time — no client-side rendering. Each post gets its own shareable URL.

Links work inline: [Visit the project](https://example.com)

## Adding your own posts

1. Create `content/posts/my-project.md`
2. Add images to `public/posts/my-project/`
3. Reference images in your markdown: `![alt](image.jpg)`
4. Push — the build pipeline does the rest.
