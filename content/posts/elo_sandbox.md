# Elo Sandbox

## What is Elo Sandbox

A tool for expressive humanoid robots
Built for the Elo Robotics design team

## The core idea
Connect animations to real inputs
Make robot faces react in real time

## Why it matters
Robots shouldn’t feel static, they should respond like companions.
The system to build them should be flexible, creative, system-driven and work with any Rive file.

## Design thinking
Feels like Figma, no learning curve for designers.
The UI is simple and easy to extend using ShadCN, this creates consistency.

## Engineering approach
Lightweight web app (Vite + React). It runs anywhere with minimal overhead.

Everything is a module, scales well and enables fast iteration for companion vibes.
